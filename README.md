# SCP Reader Commentary

Original, short commentaries on SCP Foundation articles, written in English and Japanese
for the unofficial "SCP Reader" Android app. The app downloads these files on demand.

日本語メモ: SCP 記事ごとのオリジナル解説（英語・日本語）です。アプリ「SCP Reader」が取得して表示します。
AI の支援で作成しています。ライセンスは CC BY-SA 3.0 です。

## AI-assisted authorship

Commentaries are drafted with AI assistance (Claude), checked by automated rules
(format, length, no copied passages from the article, restrained wording, valid related links),
and only partly reviewed by a human. Do not treat them as official or authoritative.

## Unofficial

This is an unofficial fan project. Not affiliated with or endorsed by the SCP Wiki or SCP-JP.

## Layout

```
en/{slug}.json     English commentary
ja/{slug}.json     Japanese commentary (written independently, not a translation)
index/en.json      {"updatedAt": "YYYY-MM-DD", "items": [{"slug": "...", "status": "..."}]}
index/ja.json      same for Japanese
```

Index files list only commentaries whose status is `ai-checked` or `reviewed`.
They are generated by the tools in the app repository (`tools/commentary/publish.py`).

## File format

```json
{
  "slug": "scp-173",
  "lang": "en",
  "hook": "No-spoiler teaser, 2-5 sentences",
  "whyItMatters": "Place in the SCP canon / community, 2-5 sentences per paragraph",
  "thingsToNotice": "Spoilers: structure, craft, foreshadowing",
  "related": [{"slug": "scp-096", "note": "one-line reason"}],
  "status": "draft | ai-checked | reviewed",
  "updatedAt": "YYYY-MM-DD"
}
```

Paragraphs inside a field are separated by a blank line.

## Status

| status | meaning |
|---|---|
| `draft` | Draft; not yet validated or failed validation. Not listed in the index. |
| `ai-checked` | Passed the automated checks. Shown in the app with an "AI-assisted" label. |
| `reviewed` | Checked and edited by a human. Shown without a label. |
